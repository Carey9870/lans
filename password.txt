Here's the updated Zod schema that enforces a **12+ character password** with your exact requirements:

- At least **12 characters** (after trimming leading/trailing spaces)
- At least **2 uppercase letters**
- At least **2 spaces** (internal spaces only — leading/trailing spaces are trimmed and not counted)
- At least **2 symbols** (non-alphanumeric characters, excluding space)
- Passwords must match

```ts
import { z } from "zod";

const passwordSchema = z
  .string()
  .trim() // Removes leading/trailing spaces automatically
  .refine((val) => val.length >= 12, {
    message: "Password must be at least 12 characters long",
  })
  .refine((val) => (val.match(/[A-Z]/g) || []).length >= 2, {
    message: "Password must contain at least 2 uppercase letters",
  })
  .refine((val) => (val.match(/ /g) || []).length >= 2, {
    message: "Password must contain at least 2 internal spaces",
  })
  .refine((val) => (val.match(/[^A-Za-z0-9\s]/g) || []).length >= 2, {
    message: "Password must contain at least 2 symbols (e.g. !@#$%^&*)",
  });

export const signupSchema = z
  .object({
    password: passwordSchema,
    confirmPassword: z.string(),
  })
  .refine((data) => data.password === data.confirmPassword, {
    message: "Passwords do not match",
    path: ["confirmPassword"],
  });
```

### Example of valid passwords:
```
My Pass@Word#2025     → valid (2 caps: M,W; 2 spaces; 2 symbols: @,#)
Hello   World!!$     → valid
A B C ! @ # 2025     → valid (but has 3 caps and 3 symbols — still passes)
```

### Example of invalid passwords:
```
mypassword123        → no uppercase, no spaces, no symbols
Hello World!         → only 1 space, only 1 symbol
  Hello   World!  $  → after trim becomes "Hello   World!  $" → only 1 symbol
Abcd Efgh Ijkl       → has spaces and uppercase but no symbols
```

### Bonus: If you want to give a more helpful combined error message

You can create a custom refiner that checks all conditions at once and returns a clear message:

```ts
const strongPasswordSchema = z.string().trim().superRefine((val, ctx) => {
  if (val.length < 12) {
    ctx.addIssue({
      code: z.ZodIssueCode.too_small,
      minimum: 12,
      type: "string",
      inclusive: true,
      message: "Password must be at least 12 characters long",
    });
  }
  if ((val.match(/[A-Z]/g) || []).length < 2) {
    ctx.addIssue({
      code: z.ZodIssueCode.custom,
      message: "Password must contain at least 2 uppercase letters",
    });
  }
  if ((val.match(/ /g) || []).length < 2) {
    ctx.addIssue({
      code: z.ZodIssueCode.custom,
      message: "Password must contain at least 2 spaces (not at start/end)",
    });
  }
  if ((val.match(/[^A-Za-z0-9\s]/g) || []).length < 2) {
    ctx.addIssue({
      code: z.ZodIssueCode.custom,
      message: "Password must contain at least 2 symbols (e.g. !@#$%^&*)",
    });
  }
});
```

Then use `password: strongPasswordSchema` in your form schema.
